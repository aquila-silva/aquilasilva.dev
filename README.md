## Sobre o projeto

Este projeto consiste em um site de portfólio desenvolvido para apresentar meus trabalhos de desenvolvimento web e estabelecer uma presença profissional na internet.

O objetivo principal é criar uma experiência simples, moderna e objetiva para que potenciais clientes possam:

- conhecer meu trabalho;
- visualizar projetos desenvolvidos;
- entender os serviços oferecidos;
- conhecer meu processo de desenvolvimento;
- entrar em contato para solicitar um projeto.

O portfólio foi pensado principalmente para divulgação através de redes sociais, contatos comerciais e prospecção de pequenos negócios.

## Funcionalidades

### Navegação responsiva

O site possui uma navegação adaptada para diferentes tamanhos de tela.

Em dispositivos menores, o menu é convertido em um botão de navegação.

---

### Menu mobile

O menu mobile possui:

- abertura e fechamento através de botão;
- atualização do atributo `aria-expanded`;
- atualização do `aria-label`;
- fechamento automático ao clicar em um link;
- suporte à tecla `Escape`;
- animação do botão de menu.

---

### Design responsivo

A interface foi desenvolvida para funcionar em diferentes dispositivos:

- Smartphones;
- Tablets;
- Notebooks;
- Desktops.

A estrutura utiliza CSS Grid, Flexbox e Media Queries para adaptar o conteúdo à largura disponível.

---

### Acessibilidade

O projeto possui algumas práticas voltadas à acessibilidade, incluindo:

- HTML semântico;
- atributos ARIA na navegação;
- estados de foco;
- navegação pelo teclado;
- suporte à tecla `Escape`;
- `aria-expanded` no menu mobile;
- `aria-label` no botão de navegação.

---

### SEO básico

O documento HTML possui configurações básicas para mecanismos de busca, incluindo:

- `title`;
- `description`;
- `keywords`;
- `author`;
- `theme-color`;
- Open Graph.
